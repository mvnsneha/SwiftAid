# 🚨 SwiftAid

SwiftAid is an AI-powered disaster response and resource allocation system that helps emergency teams make faster and smarter decisions during natural disasters. It combines real-time weather data, interactive maps, and intelligent resource allocation to simulate and optimize rescue operations.

## ✨ Features

- 🌦️ Real-time weather information
- 🗺️ Interactive disaster map
- 🤖 AI-based resource allocation
- 🚑 Rescue team simulation
- 📊 Disaster monitoring dashboard
- 📍 Route optimization using map data

## 🛠️ Tech Stack

**Frontend**
- React.js (Vite)
- React Router
- CSS

**Backend**
- Flask (Python)

**AI & Simulation**
- Reinforcement Learning
- NetworkX
- OSMnx

**APIs**
- WeatherAPI

## 🚀 Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```
